# AdventureOn legal/public website

This small static site is intended for GitHub Pages.

Files:
- `index.html` — simple landing page
- `privacy/index.html` — Privacy Policy at `/privacy/`
- `delete-account/index.html` — account deletion page at `/delete-account/`
- `styles.css` — shared styles

Recommended custom domain:
- `adventureonco.com`

After publishing with GitHub Pages, configure the custom domain in:
Repository → Settings → Pages → Custom domain

Then configure GoDaddy DNS for the apex domain using GitHub Pages' current documented DNS records.
